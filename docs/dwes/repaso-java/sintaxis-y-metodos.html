Sintaxis básica y métodos

En esta primera sesión vamos a recuperar los elementos más básicos de Java que utilizaremos continuamente durante el módulo.

No se trata de volver a aprender Java desde cero. El objetivo es volver a escribir código con soltura y recordar cómo se expresan decisiones, repeticiones y pequeñas operaciones mediante métodos.

Durante toda la sesión utilizaremos como contexto una tienda sencilla de productos.

Idea principal

Antes de trabajar con Spring Boot necesitamos sentirnos cómodos leyendo y escribiendo código Java básico.

Si sabemos interpretar variables, condiciones, bucles y métodos, podremos centrarnos después en los conceptos nuevos de Spring sin que la sintaxis de Java se convierta en un obstáculo.

1️⃣ Variables y tipos de datos​

Una variable permite almacenar un dato que podremos utilizar posteriormente en el programa.

Por ejemplo, para representar algunos datos de un producto podríamos escribir:

String nombreProducto = "Teclado";
int stock = 12;
double precio = 29.95;
boolean disponible = true;
en este ejemplo

Cada variable tiene un tipo que indica qué clase de dato puede almacenar.

  • String permite guardar texto.
  • int permite guardar números enteros.
  • double permite trabajar con números decimales.
  • boolean solo puede contener los valores true o false.

El nombre de la variable debe ayudar a entender qué información contiene.

🟩 Tipos que utilizaremos con más frecuencia​

TipoEjemploUso habitual
intint stock = 12;Cantidades enteras
doubledouble precio = 29.95;Valores con decimales
booleanboolean disponible = true;Condiciones verdadero/falso
charchar zona = 'A';Un único carácter
StringString nombre = "Teclado";Cadenas de texto
aviso

String no es un tipo primitivo como int o boolean, sino una clase de Java.

Por ahora no necesitamos profundizar en esta diferencia. Lo importante es recordar que se utiliza para trabajar con texto.

🟨 Modificar el valor de una variable​

El contenido de una variable puede cambiar durante la ejecución del programa.

int stock = 12;

stock = stock - 1;

También podemos utilizar el operador abreviado:

stock--;

Después de estas instrucciones, el valor de stock será 11.

🟧 Constantes​

Si un valor no debería cambiar, podemos utilizar final.

final double IVA = 0.21;

Por convenio, los nombres de las constantes suelen escribirse en mayúsculas.

2️⃣ Operadores​

Los operadores permiten realizar cálculos y construir condiciones.

🟩 Operadores aritméticos​

double precio = 29.95;
int cantidad = 3;

double total = precio * cantidad;

Los operadores más habituales son:

+   suma
-   resta
*   multiplicación
/   división
%   resto de la división

Otro ejemplo:

int stockInicial = 20;
int vendidos = 7;

int stockActual = stockInicial - vendidos;

🟨 Operadores de comparación​

Se utilizan para comparar valores:

==   igual que
!=   distinto de
>    mayor que
<    menor que
>=   mayor o igual que
<=   menor o igual que

Ejemplo:

boolean sinStock = stock == 0;

La variable sinStock contendrá true si no quedan unidades.

🟧 Operadores lógicos​

Permiten combinar varias condiciones.

&&   y
||   o
!    negación

Por ejemplo:

boolean sePuedeVender = stock > 0 && disponible;

En este caso deben cumplirse las dos condiciones.

3️⃣ Tomar decisiones con if​

Una estructura if permite ejecutar código únicamente cuando se cumple una condición.

int stock = 5;

if (stock > 0) {
    System.out.println("Producto disponible");
}
en este ejemplo

La expresión situada entre paréntesis debe producir un valor boolean.

Si la condición es true, se ejecuta el código situado entre las llaves.

Si es false, ese bloque se omite.

🟩 if y else​

Podemos indicar qué debe ocurrir cuando la condición no se cumple.

if (stock > 0) {
    System.out.println("Producto disponible");
} else {
    System.out.println("Producto agotado");
}

🟨 Varias posibilidades con else if​

int stock = 4;

if (stock == 0) {
    System.out.println("Producto agotado");
} else if (stock <= 5) {
    System.out.println("Quedan pocas unidades");
} else {
    System.out.println("Stock suficiente");
}
aviso

El orden de las condiciones importa.

Java comprueba las condiciones de arriba hacia abajo y se queda con el primer bloque cuya condición sea verdadera.

🟧 Comparar cadenas de texto​

Una de las confusiones más frecuentes al volver a Java aparece al comparar objetos String.

No debemos hacer esto:

if (categoria == "INFORMATICA") {
    System.out.println("Producto informático");
}

Para comparar el contenido de dos cadenas utilizamos equals():

if (categoria.equals("INFORMATICA")) {
    System.out.println("Producto informático");
}

También podemos ignorar diferencias entre mayúsculas y minúsculas:

if (categoria.equalsIgnoreCase("informatica")) {
    System.out.println("Producto informático");
}
peligro

Para comparar el contenido de objetos String, no debe utilizarse ==.

En los primeros ejercicios utilizaremos equals() o equalsIgnoreCase().

4️⃣ Elegir entre varios casos con switch​

Cuando una variable puede tomar varios valores concretos, switch puede resultar más legible que utilizar varios if y else if.

En las versiones actuales de Java podemos utilizar una sintaxis más compacta:

String categoria = "INFORMATICA";

switch (categoria) {
    case "INFORMATICA" -> System.out.println("Producto informático");
    case "HOGAR" -> System.out.println("Producto para el hogar");
    case "DEPORTE" -> System.out.println("Producto deportivo");
    default -> System.out.println("Categoría no reconocida");
}
en este ejemplo

switch compara el valor de categoria con cada uno de los casos.

Cuando encuentra una coincidencia, ejecuta la instrucción situada después de ->.

A diferencia de la sintaxis tradicional de switch, en esta forma no es necesario escribir break al final de cada caso.

🟩 Ejecutar varias instrucciones​

Si un caso necesita ejecutar más de una instrucción, podemos utilizar llaves:

switch (categoria) {
    case "INFORMATICA" -> {
        System.out.println("Producto informático");
        System.out.println("Revisa la garantía");
    }
    case "HOGAR" -> {
        System.out.println("Producto para el hogar");
        System.out.println("Consulta sus dimensiones");
    }
    default -> {
        System.out.println("Categoría no reconocida");
    }
}
tip

La sintaxis con -> es la que utilizaremos en estos apuntes.

Es más sencilla de leer y evita algunos errores habituales del switch tradicional, como olvidar un break.

🟨 ¿Cuándo utilizar switch?​

switch resulta especialmente cómodo cuando estamos comprobando un mismo valor frente a varias posibilidades concretas.

Por ejemplo:

String estado = "OFERTA";

switch (estado) {
    case "NUEVO" -> System.out.println("Producto recién añadido");
    case "OFERTA" -> System.out.println("Producto con descuento");
    case "AGOTADO" -> System.out.println("Producto sin stock");
    default -> System.out.println("Estado desconocido");
}

Si, en cambio, necesitamos comprobar condiciones diferentes como stock > 0, precio < 20 o disponible == true, normalmente será más apropiado utilizar if.

nota

Más adelante utilizaremos switch junto con enum, lo que permitirá representar categorías o estados de una forma más segura que utilizando cadenas de texto.

5️⃣ Repetir instrucciones con bucles​

Los bucles permiten ejecutar varias veces un mismo bloque de código.

En aplicaciones reales serán especialmente útiles cuando tengamos que recorrer colecciones de objetos.

🟩 Bucle for​

Si conocemos el número de repeticiones, podemos utilizar un for.

for (int i = 1; i <= 5; i++) {
    System.out.println("Producto número " + i);
}
en este ejemplo

El bucle comienza con i igual a 1.

Mientras i <= 5, se ejecuta el bloque.

Después de cada repetición, i++ incrementa su valor en una unidad.

🟨 Bucle while y do while​

while repite un bloque mientras se cumpla una condición.

int stock = 3;

while (stock > 0) {
    System.out.println("Venta realizada");
    stock--;
}

do while repite un bloque mientras se cumpla una condición, pero siempre se ejecuta la primera vez.

int stock = 3;

do {
    System.out.println("Venta realizada");
    stock--;
} while (stock > 0)

En estos ejemplo el bucle terminará cuando el stock llegue a 0.

aviso

Hay que asegurarse de que la condición del while pueda dejar de cumplirse.

Si no cambia ningún valor relacionado con la condición, podemos crear accidentalmente un bucle infinito.

6️⃣ Métodos​

Los métodos permiten agrupar instrucciones que realizan una tarea concreta.

Son fundamentales en Java y aparecerán constantemente durante todo el módulo.

Imaginemos que queremos calcular el precio total de una compra:

public static double calcularTotal(double precio, int cantidad) {
    return precio * cantidad;
}

Podemos utilizar el método así:

double total = calcularTotal(29.95, 3);

System.out.println(total);
en este ejemplo

En la declaración del método:

  • public indica su nivel de acceso.
  • static permite utilizarlo desde un contexto estático como main.
  • double indica que el método devuelve un número decimal.
  • calcularTotal es el nombre del método.
  • precio y cantidad son los parámetros.
  • return devuelve el resultado.

Más adelante trabajaremos con métodos dentro de objetos y static dejará de ser necesario en muchos casos.

🟩 Métodos que devuelven un valor​

public static double aplicarDescuento(double precio, int porcentaje) {
    return precio - (precio * porcentaje / 100.0);
}

Llamada:

double precioFinal = aplicarDescuento(100.0, 20);

La variable precioFinal contendrá 80.0.

🟨 Métodos que devuelven boolean​

También podemos crear métodos que respondan a una condición.

public static boolean hayStock(int stock) {
    return stock > 0;
}

Podemos utilizar directamente el resultado en un if:

if (hayStock(5)) {
    System.out.println("Se puede realizar la venta");
}

🟧 Métodos que no devuelven ningún valor​

Si un método realiza una acción pero no necesita devolver un resultado, utilizamos void.

public static void mostrarProducto(String nombre, double precio) {
    System.out.println(nombre + " - " + precio + " €");
}

Llamada:

mostrarProducto("Teclado", 29.95);

🟥 Parámetros y argumentos​

En este método:

public static double calcularTotal(double precio, int cantidad) {
    return precio * cantidad;
}

precio y cantidad son parámetros.

Cuando hacemos la llamada:

calcularTotal(12.50, 4);

12.50 y 4 son los argumentos que enviamos al método.

7️⃣ El ámbito de las variables​

Una variable solo puede utilizarse dentro del bloque en el que ha sido declarada.

public static void mostrarEstado(int stock) {

    String mensajeGeneral = "Estado del producto";

    if (stock > 0) {
        String mensajeStock = "Hay unidades disponibles";
        System.out.println(mensajeStock);
    }

    System.out.println(mensajeGeneral);
}

La variable mensajeGeneral pertenece al método completo.

Sin embargo, esta instrucción produciría un error fuera del if:

System.out.println(mensajeStock);

porque mensajeStock solo existe dentro de ese bloque.

Idea principal

Cuando una variable se declara dentro de unas llaves { }, normalmente deja de estar disponible al salir de ese bloque.

8️⃣ Ejemplo guiado: información de un producto​

Vamos a reunir varias de las ideas anteriores.

public class Main {

    public static void main(String[] args) {

        String nombre = "Teclado mecánico";
        double precio = 59.95;
        int stock = 4;
        boolean disponible = true;

        mostrarResumen(nombre, precio, stock, disponible);
    }

    public static void mostrarResumen(
            String nombre,
            double precio,
            int stock,
            boolean disponible) {

        System.out.println("Producto: " + nombre);
        System.out.println("Precio: " + precio + " €");

        if (!disponible || stock == 0) {
            System.out.println("Producto no disponible");
        } else if (stock <= 5) {
            System.out.println("Quedan pocas unidades");
        } else {
            System.out.println("Stock suficiente");
        }
    }
}
en este ejemplo

El programa almacena los datos de un producto y llama al método mostrarResumen().

Dentro del método se utilizan varias condiciones para mostrar mensajes diferentes según la disponibilidad y el stock.

Aunque el ejemplo sigue siendo sencillo, ya aparecen variables, métodos, parámetros, condiciones y operadores lógicos.

9️⃣ Práctica guiada​

A partir de los ejemplos anteriores, realiza las siguientes modificaciones.

🟩 Paso 1. Comprobar si hay stock​

Crea un método:

public static boolean hayStock(int stock)

Debe devolver true si queda al menos una unidad.

🟨 Paso 2. Calcular el total de una compra​

Crea un método:

public static double calcularTotal(double precio, int cantidad)

Debe devolver el precio total.

🟧 Paso 3. Aplicar un descuento​

Crea un método:

public static double aplicarDescuento(double precio, int porcentaje)

Por ejemplo:

aplicarDescuento(20.0, 25)

debería devolver:

15.0

🟥 Paso 4. Clasificar el stock​

Crea un método:

public static String obtenerEstadoStock(int stock)

Debe devolver:

"AGOTADO"

si el stock es 0,

"POCAS UNIDADES"

si quedan 5 unidades o menos,

y:

"DISPONIBLE"

en cualquier otro caso.

tip

Intenta resolver primero cada método sin consultar la solución de ejercicios anteriores.

🔟 Qué debes recordar​

Antes de terminar esta primera sesión, conviene comprobar que estas ideas vuelven a resultar familiares:

  • una variable almacena un dato;
  • cada variable tiene un tipo;
  • if permite tomar decisiones;
  • for y while permiten repetir instrucciones;
  • equals() se utiliza para comparar el contenido de String;
  • un método agrupa una tarea;
  • los parámetros permiten enviar información a un método;
  • return devuelve un resultado;
  • void indica que un método no devuelve ningún valor;
  • las variables tienen un ámbito determinado.
