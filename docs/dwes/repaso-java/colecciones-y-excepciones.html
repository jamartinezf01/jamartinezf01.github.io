Colecciones y excepciones

Hasta ahora hemos trabajado con productos individuales. En una aplicación real necesitaremos manejar muchos objetos al mismo tiempo.

Para ello utilizaremos colecciones, especialmente List y ArrayList.

En esta última sesión del repaso también recuperaremos el manejo básico de excepciones, suficiente para controlar algunos errores habituales antes de comenzar con Spring Boot.

Idea principal

En muchas aplicaciones no trabajamos con un único objeto, sino con grupos de objetos.

Una colección nos permite almacenar, recorrer, buscar, añadir o eliminar esos objetos de una forma organizada.

1️⃣ ¿Qué es una colección?​

Una colección permite almacenar varios elementos dentro de una misma estructura.

Por ejemplo, en lugar de tener variables independientes:

Producto producto1 = new Producto("Teclado", 29.95, 10);
Producto producto2 = new Producto("Ratón", 19.90, 8);
Producto producto3 = new Producto("Monitor", 149.90, 4);

podemos guardar todos esos productos en una lista.

List<Producto> productos = new ArrayList<>();
en este ejemplo

List<Producto> indica que la colección almacenará objetos de tipo Producto.

ArrayList es una implementación de List que permite añadir, eliminar y recorrer elementos fácilmente.

🟩 Importaciones necesarias​

Para utilizar estas clases debemos importarlas:

import java.util.ArrayList;
import java.util.List;

Después ya podemos crear la colección:

List<Producto> productos = new ArrayList<>();

2️⃣ Añadir elementos a una lista​

Podemos añadir objetos con el método add().

Producto teclado = new Producto("Teclado", 29.95, 10);
Producto raton = new Producto("Ratón", 19.90, 8);

productos.add(teclado);
productos.add(raton);

También podemos crear y añadir el objeto directamente:

productos.add(new Producto("Monitor", 149.90, 4));
tip

Ambas formas son correctas.

Crear primero una variable puede resultar más cómodo si vamos a utilizar ese objeto varias veces.

🟨 Consultar el tamaño​

Podemos saber cuántos elementos contiene la lista con:

System.out.println(productos.size());

Si hay tres productos, el resultado será:

3

🟧 Acceder a una posición​

Las posiciones de una lista comienzan en 0.

Producto primero = productos.get(0);

Si queremos consultar el nombre:

System.out.println(productos.get(0).getNombre());
aviso

Intentar acceder a una posición que no existe provoca un error.

Por ejemplo, si la lista tiene tres elementos, las posiciones válidas son 0, 1 y 2.

3️⃣ Recorrer una lista​

Una de las operaciones más frecuentes consiste en recorrer todos sus elementos.

🟩 for-each​

Para trabajar con objetos, una forma muy cómoda es el bucle for-each.

for (Producto producto : productos) {
    System.out.println(producto.getNombre());
}
en este ejemplo

En cada vuelta del bucle, la variable producto hace referencia a uno de los objetos almacenados en la lista.

No necesitamos trabajar directamente con posiciones.

Podemos mostrar más información:

for (Producto producto : productos) {
    System.out.println(
        producto.getNombre() + " - "
        + producto.getPrecio() + " €"
    );
}

🟨 for tradicional​

También podemos recorrer una lista mediante índices:

for (int i = 0; i < productos.size(); i++) {
    Producto producto = productos.get(i);
    System.out.println(producto.getNombre());
}

Esta forma resulta útil cuando necesitamos conocer la posición del elemento.

tip

Siempre que no necesitemos trabajar con posiciones, el for-each suele resultar más sencillo de leer.

4️⃣ Buscar un producto​

Una operación muy habitual es localizar un objeto concreto dentro de una colección.

Podemos crear un método sencillo:

public static Producto buscarProducto(
        List<Producto> productos,
        String nombre) {

    for (Producto producto : productos) {
        if (producto.getNombre().equalsIgnoreCase(nombre)) {
            return producto;
        }
    }

    return null;
}
en este ejemplo

El método recorre la lista producto a producto.

Si encuentra uno cuyo nombre coincide, devuelve ese objeto inmediatamente.

Si termina el recorrido sin encontrarlo, devuelve null.

Podemos utilizarlo así:

Producto encontrado = buscarProducto(productos, "Teclado");

if (encontrado != null) {
    System.out.println(encontrado.getPrecio());
} else {
    System.out.println("Producto no encontrado");
}
aviso

null significa que no tenemos ningún objeto.

Antes de utilizar métodos sobre una variable que puede contener null, debemos comprobar su valor.

5️⃣ Eliminar elementos​

Podemos eliminar un objeto concreto con remove().

productos.remove(teclado);

También podemos eliminar por posición:

productos.remove(0);

Pero normalmente será más claro localizar primero el objeto.

Producto encontrado = buscarProducto(productos, "Ratón");

if (encontrado != null) {
    productos.remove(encontrado);
}

🟩 Método para eliminar un producto​

Podemos encapsular esta operación en un método:

public static boolean eliminarProducto(
        List<Producto> productos,
        String nombre) {

    Producto producto = buscarProducto(productos, nombre);

    if (producto != null) {
        productos.remove(producto);
        return true;
    }

    return false;
}

Y utilizarlo así:

if (eliminarProducto(productos, "Ratón")) {
    System.out.println("Producto eliminado");
} else {
    System.out.println("No se encontró el producto");
}

6️⃣ Modificar objetos de una colección​

Una lista almacena referencias a objetos.

Eso significa que, si recuperamos uno y lo modificamos, el cambio afecta al objeto almacenado.

Producto producto = buscarProducto(productos, "Teclado");

if (producto != null) {
    producto.setPrecio(24.95);
}

No necesitamos volver a añadirlo a la lista.

Idea principal

La lista contiene referencias a los objetos.

Si modificamos uno de esos objetos mediante sus métodos, el cambio se conserva dentro de la colección.

Otro ejemplo:

if (producto != null) {
    producto.reponerStock(5);
}

7️⃣ Filtrar productos con un recorrido​

También podemos recorrer una lista y mostrar solo los elementos que cumplen una condición.

Por ejemplo, productos con stock:

for (Producto producto : productos) {
    if (producto.hayStock()) {
        System.out.println(producto.getNombre());
    }
}

O productos baratos:

for (Producto producto : productos) {
    if (producto.getPrecio() < 20) {
        System.out.println(producto.getNombre());
    }
}
nota

Más adelante existen otras formas de filtrar colecciones, como Streams.

En este repaso utilizaremos bucles porque permiten ver claramente qué está ocurriendo en cada paso.

8️⃣ Una clase para gestionar productos​

Hasta ahora estamos trabajando directamente con una lista desde main.

Podemos mejorar la organización creando una clase encargada de gestionar los productos.

import java.util.ArrayList;
import java.util.List;

public class Tienda {

    private List<Producto> productos;

    public Tienda() {
        productos = new ArrayList<>();
    }

    public void agregarProducto(Producto producto) {
        productos.add(producto);
    }

    public void mostrarProductos() {
        for (Producto producto : productos) {
            System.out.println(
                producto.getNombre() + " - "
                + producto.getPrecio() + " €"
            );
        }
    }
}
en este ejemplo

La clase Tienda contiene una lista de productos.

De esta forma, la lógica relacionada con la gestión de productos deja de estar dispersa por el programa.

Todavía no estamos trabajando con Spring Boot, pero esta separación nos ayuda a preparar la forma de organizar el código que veremos más adelante.

🟩 Añadir búsqueda​

Podemos incluir también:

public Producto buscarProducto(String nombre) {

    for (Producto producto : productos) {
        if (producto.getNombre().equalsIgnoreCase(nombre)) {
            return producto;
        }
    }

    return null;
}

Ahora la llamada sería:

Producto producto = tienda.buscarProducto("Teclado");

🟨 Añadir eliminación​

public boolean eliminarProducto(String nombre) {

    Producto producto = buscarProducto(nombre);

    if (producto != null) {
        productos.remove(producto);
        return true;
    }

    return false;
}

9️⃣ Excepciones: cuando algo sale mal​

Durante la ejecución de un programa pueden producirse errores.

Por ejemplo:

int numero = Integer.parseInt("abc");

Este código intenta convertir "abc" en un número entero, algo que no es posible.

Java genera entonces una excepción.

Idea principal

Una excepción representa una situación anómala que ocurre durante la ejecución del programa.

Podemos capturar algunas excepciones para evitar que el programa termine de forma abrupta.

🟩 try y catch​

Podemos controlar el error anterior así:

try {
    int cantidad = Integer.parseInt("abc");
    System.out.println(cantidad);
} catch (NumberFormatException e) {
    System.out.println("La cantidad debe ser un número");
}
en este ejemplo

El bloque try contiene el código que puede provocar una excepción.

Si se produce una NumberFormatException, Java salta al bloque catch.

El programa puede continuar ejecutándose después.

🟨 Ejemplo aplicado a la tienda​

Imaginemos que recibimos una cantidad como texto:

String textoCantidad = "5";

Podemos convertirla así:

try {
    int cantidad = Integer.parseInt(textoCantidad);
    System.out.println("Cantidad: " + cantidad);
} catch (NumberFormatException e) {
    System.out.println("Cantidad no válida");
}

🔟 No utilizar excepciones para todo​

Las excepciones no sustituyen a las validaciones normales.

Por ejemplo, para comprobar si hay stock:

if (producto.getStock() > 0) {
    producto.venderUnidad();
}

No tendría sentido provocar un error y capturarlo después.

aviso

Utiliza condiciones para situaciones previsibles y excepciones para errores que realmente pueden producirse durante la ejecución.

1️⃣1️⃣ Ejemplo integrador​

Vamos a reunir los conceptos principales.

import java.util.ArrayList;
import java.util.List;

public class Main {

    public static void main(String[] args) {

        List<Producto> productos = new ArrayList<>();

        productos.add(new Producto("Teclado", 29.95, 10));
        productos.add(new Producto("Ratón", 19.90, 8));
        productos.add(new Producto("Monitor", 149.90, 4));

        mostrarProductos(productos);

        Producto encontrado = buscarProducto(productos, "Ratón");

        if (encontrado != null) {
            System.out.println(
                "Encontrado: " + encontrado.getNombre()
            );
        }
    }

    public static void mostrarProductos(List<Producto> productos) {

        for (Producto producto : productos) {
            System.out.println(
                producto.getNombre() + " - "
                + producto.getPrecio() + " €"
            );
        }
    }

    public static Producto buscarProducto(
            List<Producto> productos,
            String nombre) {

        for (Producto producto : productos) {
            if (producto.getNombre().equalsIgnoreCase(nombre)) {
                return producto;
            }
        }

        return null;
    }
}
en este ejemplo

Este programa crea una colección de productos, añade varios objetos, recorre la lista y permite realizar una búsqueda.

Aquí aparecen juntos varios conceptos recuperados durante las tres sesiones:

  • clases y objetos;
  • métodos;
  • parámetros;
  • if;
  • bucles;
  • List;
  • ArrayList;
  • null;
  • relaciones entre objetos y colecciones.

1️⃣2️⃣ Práctica guiada​

A partir de las clases Producto y Tienda, completa las siguientes operaciones.

🟩 Paso 1. Añadir productos​

Crea varios productos y añádelos a la tienda.

Como mínimo:

Teclado
Ratón
Monitor
Auriculares
Webcam

🟨 Paso 2. Mostrar productos​

Añade un método que muestre todos los productos con este formato:

Teclado - 29.95 € - Stock: 10

🟧 Paso 3. Buscar un producto​

Implementa:

public Producto buscarProducto(String nombre)

Debe devolver el producto encontrado o null.

🟥 Paso 4. Eliminar un producto​

Implementa:

public boolean eliminarProducto(String nombre)

Debe devolver true si se elimina y false si no existe.

🟪 Paso 5. Mostrar productos con stock​

Crea un método:

public void mostrarProductosDisponibles()

Debe mostrar únicamente los productos cuyo stock sea mayor que 0.

🟩 Paso 6. Calcular el valor total​

Crea un método:

public double calcularValorTotal()

Debe sumar:

precio × stock

de todos los productos de la tienda.

🟨 Paso 7. Controlar una cantidad introducida como texto​

Parte de:

String cantidadTexto = "abc";

Intenta convertirla a int con Integer.parseInt() y controla el posible error mediante try y catch.

tip

No necesitas resolver todos los pasos a la vez.

Prueba cada método antes de continuar con el siguiente.

1️⃣3️⃣ Qué debes recordar​

Al terminar este bloque de repaso conviene tener claras estas ideas:

  • List representa una colección ordenada;
  • ArrayList permite almacenar varios objetos;
  • add() añade elementos;
  • get() accede a una posición;
  • size() devuelve el número de elementos;
  • remove() elimina elementos;
  • for-each permite recorrer colecciones cómodamente;
  • podemos buscar objetos recorriendo una lista;
  • null indica ausencia de objeto;
  • modificar un objeto recuperado de una lista modifica ese mismo objeto;
  • try y catch permiten controlar algunas excepciones.
