Actividades de repaso

Estas actividades sirven para recuperar soltura con Java antes de comenzar a trabajar con Spring Boot.

No constituyen una unidad evaluable ni tienen entrega asociada. Su finalidad es practicar, detectar dudas y comprobar qué conceptos necesitan un refuerzo adicional.

Todas las actividades utilizan como contexto una tienda sencilla de productos.

Carácter de las actividades

Estas actividades son no evaluables.

No hay entrega ni criterios de calificación. Se utilizarán como práctica y como diagnóstico previo al inicio de Spring Boot.

1️⃣ Actividades de la primera sesión​

En esta primera sesión se repasan variables, operadores, condiciones, bucles y métodos.

🟩 Actividad 1. Datos de un producto​

Crea un programa que almacene la información de un producto utilizando variables independientes.

Debe incluir, al menos:

nombre
precio
stock
disponible

Después muestra la información por pantalla.

Ejemplo orientativo:

Producto: Teclado
Precio: 29.95 €
Stock: 12
Disponible: true

🟨 Actividad 2. Estado del stock​

A partir de una variable:

int stock = 4;

muestra uno de estos mensajes:

Producto agotado
Quedan pocas unidades
Stock suficiente

Utiliza estas reglas:

  • si stock == 0 → producto agotado;
  • si stock <= 5 → quedan pocas unidades;
  • en cualquier otro caso → stock suficiente.

🟧 Actividad 3. Calcular el precio total​

Crea un método:

public static double calcularTotal(double precio, int cantidad)

Debe devolver el precio total de una compra.

Prueba el método con varios valores.

Por ejemplo:

calcularTotal(10.0, 3)

debe devolver:

30.0

🟥 Actividad 4. Aplicar un descuento​

Crea un método:

public static double aplicarDescuento(double precio, int porcentaje)

Ejemplo:

aplicarDescuento(100, 20)

debe devolver:

80.0

🟪 Actividad 5. Clasificar un producto​

Crea una variable:

String categoria = "INFORMATICA";

Utiliza un switch moderno para mostrar un mensaje según la categoría.

Como mínimo:

INFORMATICA
HOGAR
DEPORTE

Utiliza la sintaxis:

case "..." -> ...

🟩 Actividad 6. Repetir ventas​

Parte de:

int stock = 5;

Utiliza un bucle while para simular ventas hasta que el stock llegue a 0.

En cada vuelta debe mostrarse el stock restante.

Ejemplo:

Venta realizada. Stock: 4
Venta realizada. Stock: 3
Venta realizada. Stock: 2
Venta realizada. Stock: 1
Venta realizada. Stock: 0
tip

En esta primera sesión interesa recuperar la sintaxis y la lógica básica.

No intentes hacer soluciones demasiado complejas. Si una solución sencilla funciona y se entiende, es suficiente.

2️⃣ Actividades de la segunda sesión​

En esta sesión se repasan clases, objetos, constructores, encapsulación, métodos de instancia, relaciones entre objetos y enum.

🟩 Actividad 7. Crear la clase Producto​

Crea una clase Producto con estos atributos:

nombre
precio
stock

Todos los atributos deben ser private.

Añade un constructor que permita inicializar los tres valores.

🟨 Actividad 8. Añadir getters y setters​

Añade los getters necesarios.

Añade también un setter para el precio:

public void setPrecio(double precio)

El precio solo debe modificarse si el valor recibido es mayor o igual que 0.

🟧 Actividad 9. Añadir comportamiento​

Añade estos métodos a Producto:

public boolean hayStock()

Debe devolver true cuando el stock sea mayor que 0.

public void venderUnidad()

Debe reducir el stock en una unidad únicamente cuando queden unidades disponibles.

public void reponerStock(int cantidad)

Debe aumentar el stock únicamente cuando la cantidad sea positiva.

🟥 Actividad 10. Crear varios objetos​

Desde main, crea al menos tres productos.

Por ejemplo:

Teclado
Ratón
Monitor

Realiza algunas operaciones:

  • muestra su información;
  • vende una unidad;
  • cambia el precio;
  • repón stock.

Comprueba después que cada objeto mantiene su propio estado.

🟪 Actividad 11. Crear una categoría​

Crea una clase:

Categoria

con:

nombre
descripcion

Añade constructor y getters.

Después relaciona un Producto con una Categoria.

🟩 Actividad 12. Crear un enum​

Crea:

public enum EstadoProducto {
    NUEVO,
    OFERTA,
    AGOTADO
}

Añade un atributo de tipo EstadoProducto a la clase Producto.

Crea varios productos con estados diferentes.

🟨 Actividad 13. Mostrar el estado con switch​

Utiliza un switch moderno para mostrar mensajes distintos según el estado.

Por ejemplo:

Producto nuevo
Producto con descuento
Producto sin stock
aviso

Comprueba que el proyecto compila después de cada cambio.

Cuando se añaden varias clases y relaciones entre objetos, es mucho más sencillo detectar un error si se prueba el código paso a paso.

3️⃣ Actividades de la tercera sesión​

En esta sesión se repasan colecciones, recorridos, búsquedas, modificaciones, eliminaciones y excepciones básicas.

🟩 Actividad 14. Crear una lista de productos​

Crea:

List<Producto> productos = new ArrayList<>();

Añade al menos cinco productos.

Por ejemplo:

Teclado
Ratón
Monitor
Auriculares
Webcam

🟨 Actividad 15. Mostrar todos los productos​

Recorre la lista con for-each.

Muestra cada producto con este formato:

Teclado - 29.95 € - Stock: 10

🟧 Actividad 16. Buscar un producto​

Crea:

public static Producto buscarProducto(
        List<Producto> productos,
        String nombre)

Debe:

  • recorrer la lista;
  • comparar el nombre con equalsIgnoreCase();
  • devolver el producto si lo encuentra;
  • devolver null si no existe.

🟥 Actividad 17. Eliminar un producto​

Crea:

public static boolean eliminarProducto(
        List<Producto> productos,
        String nombre)

Debe devolver:

true

si el producto se elimina,

y:

false

si no existe.

🟪 Actividad 18. Mostrar productos disponibles​

Recorre la colección y muestra únicamente aquellos productos cuyo stock sea mayor que 0.

🟩 Actividad 19. Calcular el valor del almacén​

Calcula cuánto dinero representa todo el stock de la tienda.

Para cada producto:

precio × stock

Después suma el resultado de todos.

Puedes crear:

public static double calcularValorTotal(List<Producto> productos)

🟨 Actividad 20. Controlar una entrada incorrecta​

Parte de:

String cantidadTexto = "abc";

Intenta convertirla a entero con:

Integer.parseInt(cantidadTexto)

Controla el posible error mediante:

try

y:

catch

Muestra un mensaje claro si el valor no puede convertirse.

4️⃣ Reto final: gestión básica de una tienda​

Para cerrar el repaso, crea una pequeña aplicación que reúna los conceptos trabajados durante las tres sesiones.

No hace falta desarrollar una aplicación completa ni utilizar Spring Boot todavía.

🟩 Objetivo​

Crear una aplicación Java capaz de gestionar una pequeña colección de productos en memoria.

🟨 Requisitos mínimos​

La aplicación debe incluir una clase:

Producto

con, al menos:

nombre
precio
stock
estado

También debe existir una clase:

Tienda

que contenga:

List<Producto> productos

La clase Tienda debe permitir realizar estas operaciones:

añadir producto
mostrar productos
buscar producto
eliminar producto
mostrar productos disponibles
calcular el valor total del stock

🟧 Posible menú​

Si quieres practicar también estructuras de control, puedes añadir un menú sencillo:

=== TIENDA ===

1. Mostrar productos
2. Buscar producto
3. Añadir producto
4. Eliminar producto
5. Mostrar productos con stock
6. Calcular valor total
0. Salir
nota

El menú es opcional.

Lo importante es practicar correctamente las clases, los objetos, los métodos y las colecciones. No merece la pena dedicar demasiado tiempo a la entrada por teclado si todavía hay dudas con los conceptos principales.

🟥 Ejemplo de salida​

Una ejecución podría mostrar algo parecido a:

=== PRODUCTOS ===

Teclado - 29.95 € - Stock: 10
Ratón - 19.90 € - Stock: 8
Monitor - 149.90 € - Stock: 4

Valor total del stock: 1058.30 €

🟪 Mejoras opcionales​

Si terminas con tiempo, puedes añadir alguna de estas mejoras:

  • impedir productos con precio negativo;
  • impedir stock negativo;
  • comprobar si ya existe un producto con el mismo nombre;
  • modificar el precio de un producto;
  • reponer stock;
  • mostrar únicamente los productos en oferta;
  • ordenar la salida de forma más clara.
tip

Las mejoras son opcionales.

Es preferible tener una solución sencilla y bien entendida que una aplicación más grande con código que no se comprende.

5️⃣ Comprobación final​

Antes de comenzar con Spring Boot, comprueba si puedes responder afirmativamente a estas preguntas:

  • ¿Sé declarar variables y utilizar condiciones?
  • ¿Sé crear y llamar a un método?
  • ¿Entiendo qué son los parámetros y return?
  • ¿Sé crear una clase?
  • ¿Sé crear objetos con new?
  • ¿Entiendo para qué sirve un constructor?
  • ¿Sé utilizar this?
  • ¿Sé trabajar con atributos private?
  • ¿Sé utilizar getters y setters?
  • ¿Sé crear métodos de instancia?
  • ¿Entiendo que un objeto puede contener otro objeto?
  • ¿Sé crear y utilizar un enum?
  • ¿Sé crear una List<Producto>?
  • ¿Sé recorrerla con for-each?
  • ¿Sé buscar y eliminar objetos?
  • ¿Entiendo qué significa null?
  • ¿Recuerdo para qué sirven try y catch?
Si alguna respuesta es "no"

No significa que haya que volver a estudiar todo Java.

Localiza el concepto concreto en los apuntes de repaso, revisa el ejemplo correspondiente y vuelve a realizar una actividad sencilla relacionada con él.

6️⃣ Preparados para Spring Boot​

Durante estas actividades hemos trabajado con una aplicación Java que mantiene sus productos en memoria.

Hasta ahora tenemos algo parecido a:

Programa Java
     ↓
Tienda
     ↓
List<Producto>

Cuando empecemos con Spring Boot aparecerán nuevos elementos relacionados con el desarrollo web.

Sin embargo, seguiremos utilizando exactamente muchas de las herramientas que acabamos de repasar:

clases
objetos
métodos
parámetros
colecciones
relaciones entre objetos
Idea final

El objetivo de este repaso no es saber más Java que antes del verano.

El objetivo es recuperar suficiente soltura para que, cuando aparezcan los conceptos nuevos de Spring Boot, podamos centrarnos en entender Spring y no en recordar cómo funciona Java.
