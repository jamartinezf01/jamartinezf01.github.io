Repaso de Java

Antes de comenzar a desarrollar aplicaciones web con Spring Boot, conviene recuperar algunos conceptos de Java que se utilizarán de forma constante durante el módulo.

Este bloque no pretende volver a estudiar Java desde cero. El objetivo es recordar, de forma rápida y práctica, aquellas ideas que serán necesarias para comprender los ejemplos que aparecerán más adelante: métodos, clases, objetos, relaciones entre objetos y colecciones.

Durante el repaso se utilizará como hilo conductor una pequeña aplicación de gestión de eventos. A medida que avancemos iremos incorporando nuevos elementos: eventos, usuarios, inscripciones y operaciones para consultar o modificar la información.

Idea principal

Spring Boot no sustituye a Java.

Cuando empecemos a trabajar con controladores, servicios o repositorios seguiremos escribiendo clases, creando objetos, llamando a métodos y utilizando colecciones. Por eso es importante recuperar primero estas bases.

1️⃣ ¿Por qué hacemos este repaso?​

Después de un periodo sin programar es normal haber olvidado parte de la sintaxis o necesitar unos minutos para recordar cómo se construía una clase, cómo funcionaba un constructor o cómo se recorría una lista.

El problema aparece cuando esas dudas se mezclan con conceptos nuevos de Spring Boot. Si al mismo tiempo hay que entender qué hace @Controller, qué representa una ruta y cómo funciona una petición HTTP, recordar qué era un método o un objeto puede dificultar innecesariamente el aprendizaje.

Por eso, antes de comenzar con Spring Boot dedicaremos unas sesiones a recuperar los conceptos esenciales de Java.

No será un repaso exhaustivo. Nos centraremos únicamente en aquello que necesitaremos de forma inmediata.

🟩 Qué deberíamos recuperar​

Al finalizar este bloque deberíamos ser capaces de leer y escribir con cierta soltura código Java que utilice:

  • variables y tipos de datos;
  • estructuras condicionales y bucles;
  • métodos con parámetros y valores de retorno;
  • clases, atributos y objetos;
  • constructores y la palabra clave this;
  • encapsulación mediante métodos de acceso;
  • relaciones sencillas entre objetos;
  • enumeraciones (enum);
  • colecciones con List y ArrayList;
  • recorridos, búsquedas y modificaciones sobre colecciones;
  • excepciones básicas.
aviso

No es necesario recordar toda la sintaxis de memoria.

Lo importante es reconocer los conceptos, entender qué está haciendo el código y ser capaces de consultar la documentación o los apuntes cuando aparezca alguna duda concreta.

🟨 Qué no vamos a repasar ahora​

Java ofrece muchas más posibilidades de las que necesitamos para comenzar con Spring Boot.

En este bloque no profundizaremos todavía en:

  • herencia compleja;
  • genéricos avanzados;
  • expresiones lambda;
  • Streams;
  • concurrencia;
  • acceso a bases de datos;
  • ficheros;
  • patrones de diseño.

Algunos de estos contenidos aparecerán más adelante si son necesarios.

Idea principal

El objetivo no es dominar todas las posibilidades de Java, sino recuperar una base suficientemente sólida para que los conceptos nuevos de Spring Boot no se mezclen con dudas de programación básica.

2️⃣ De Java a Spring Boot​

Al terminar este repaso seguiremos trabajando con Java, pero cambiaremos el tipo de aplicación que estamos construyendo.

En una aplicación Java sencilla podríamos tener algo parecido a:

Programa Java
     ↓
Lista de eventos
     ↓
Operaciones sobre los eventos

Cuando empecemos con Spring Boot aparecerán nuevos elementos:

Navegador
     ↓
Controller
     ↓
Lógica de la aplicación
     ↓
Datos

No es necesario comprender todavía esta estructura.

Lo importante es quedarse con una idea:

Spring Boot añadirá herramientas para construir aplicaciones web, pero debajo seguiremos trabajando con clases, objetos, métodos y colecciones de Java.

3️⃣ Carácter del bloque​

Este repaso tiene carácter preparatorio y no evaluable.

No constituye una unidad de trabajo independiente ni se asociará a un resultado de aprendizaje concreto. Su finalidad es recuperar conocimientos previos necesarios para comenzar con garantías los contenidos del módulo.

Las actividades servirán para practicar, detectar dudas y comprobar qué conceptos necesitan un refuerzo adicional.

tip

Si durante las primeras unidades aparece alguna duda relacionada con Java, estos apuntes podrán utilizarse también como material de consulta.
