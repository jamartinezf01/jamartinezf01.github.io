UT2. Controladores, vistas y Thymeleaf

En la unidad anterior se estudió cómo funciona una aplicación web en entorno servidor y se dieron los primeros pasos con Spring Boot. Ya se conoce la idea general de una petición HTTP, el papel del servidor y la forma en la que un controlador puede encargarse de atender una ruta.

En esta unidad se dará un paso más: en lugar de responder únicamente con texto, se construirán páginas HTML dinámicas cuyo contenido se genera en el servidor.

Para ello se utilizará Thymeleaf, un motor de plantillas que se integra con Spring Boot y que permite combinar una plantilla HTML con los datos preparados por la aplicación Java.

Idea principal

A lo largo de esta unidad se aprenderá a conectar tres piezas fundamentales de una aplicación web:

controlador → datos → vista

El controlador atenderá la petición, preparará los datos necesarios y seleccionará la plantilla que se utilizará para generar la respuesta HTML.

1️⃣ Qué vamos a aprender​

Hasta ahora se ha trabajado principalmente con el recorrido de una petición y con controladores sencillos. En esta unidad se empezarán a construir aplicaciones que generan páginas diferentes según los datos disponibles en el servidor.

Al finalizar, el alumnado deberá ser capaz de:

  • crear controladores y asociarlos a distintas rutas.
  • devolver vistas HTML desde Spring Boot.
  • utilizar Model para enviar información desde un controlador hasta una vista.
  • comprender qué es Thymeleaf y qué papel desempeña dentro de una aplicación Spring Boot.
  • mostrar variables y propiedades de objetos en una plantilla.
  • utilizar expresiones y operadores.
  • generar contenido de forma condicional.
  • recorrer colecciones para construir listados y tablas.
  • reutilizar partes comunes de varias páginas mediante fragmentos.
  • organizar y utilizar recursos estáticos como hojas de estilo, imágenes o JavaScript.
  • reconocer cómo encajan todas estas piezas dentro del patrón MVC.

No se utilizará todavía una base de datos. Los datos de los ejemplos se crearán directamente desde Java para poder concentrarse en comprender cómo se comunican el controlador y la vista.

aviso

En esta unidad se trabajará la generación de la respuesta que recibe el navegador.

La recepción y procesamiento de datos introducidos por el usuario mediante formularios se estudiará más adelante, por lo que todavía no se profundizará en @PostMapping, binding de formularios, validación o persistencia.

3️⃣ El paso que vamos a dar​

Una página HTML escrita directamente en un archivo siempre contiene la misma información. Esto puede ser suficiente para una página estática, pero una aplicación web necesita mostrar información que cambia.

Por ejemplo, una aplicación podría necesitar mostrar:

  • el nombre del usuario que ha iniciado sesión.
  • una lista de productos.
  • los eventos disponibles para una fecha determinada.
  • un mensaje diferente dependiendo de una condición.
  • una tabla cuyo número de filas depende de los datos disponibles.

Ese HTML no puede estar completamente escrito de antemano.

Spring Boot puede preparar los datos y Thymeleaf puede utilizarlos para generar el documento HTML que finalmente se enviará al navegador.

El flujo básico que se irá construyendo durante la unidad será el siguiente:

Navegador
    ↓ petición
Controller
    ↓
Model
    ↓
Plantilla Thymeleaf
    ↓
HTML generado
    ↓ respuesta
Navegador

tip

El navegador no ejecuta Thymeleaf.

Las expresiones de Thymeleaf se procesan en el servidor. El navegador recibe finalmente un documento HTML normal.

4️⃣ Contenidos de la unidad​

La unidad se desarrollará de forma progresiva. Se empezará por los controladores y se terminará reuniendo todo lo aprendido para comprender el patrón MVC.

🟩 1. Controladores y rutas​

Se trabajará con @Controller y @GetMapping para definir qué métodos deben responder a las distintas rutas de la aplicación.

🟨 2. Devolución de vistas desde Spring Boot​

Se verá cómo un controlador puede devolver el nombre de una plantilla HTML y cómo Spring Boot localiza las vistas almacenadas en src/main/resources/templates.

🟧 3. Uso de Model​

Se utilizará Model para transportar información desde el controlador hasta la vista mediante atributos.

Se comenzará con valores sencillos y se avanzará hacia objetos Java y colecciones.

🟥 4. Plantillas Thymeleaf​

Se estudiará qué es un motor de plantillas, por qué se necesita Thymeleaf y cómo se integra con Spring Boot para generar HTML dinámicamente.

🟪 5. Variables y expresiones​

Se aprenderá a recuperar en una plantilla los valores enviados desde el controlador, acceder a propiedades de objetos y construir enlaces mediante las expresiones de Thymeleaf.

🟩 6. Operadores​

Se utilizarán operadores sencillos dentro de las expresiones para realizar comparaciones y construir condiciones.

🟨 7. Condicionales​

Se generará contenido diferente dependiendo del valor de los datos mediante atributos como th:if y th:unless.

🟧 8. Bucles y colecciones​

Se utilizará th:each para recorrer colecciones de objetos y generar automáticamente listados y tablas.

🟥 9. Fragmentos y plantillas reutilizables​

Se evitará repetir el mismo HTML en distintas páginas creando fragmentos reutilizables para elementos como la cabecera, el menú de navegación o el pie.

🟪 10. Recursos estáticos​

Se organizarán hojas de estilo, imágenes y otros recursos dentro de src/main/resources/static y se aprenderá a utilizarlos desde las vistas.

🟩 11. El patrón MVC: cómo encaja todo​

Al final de la unidad se reunirán todas las piezas para identificar claramente el Modelo, la Vista y el Controlador, y comprender por qué esta separación facilita la organización de una aplicación web.

5️⃣ Cómo trabajaremos​

Los conceptos de esta unidad están muy relacionados entre sí, por lo que se irá ampliando progresivamente una misma aplicación.

No se trata de memorizar anotaciones o atributos de Thymeleaf de forma aislada. Lo importante será comprender qué responsabilidad tiene cada parte del programa y seguir el recorrido de los datos desde que llega una petición hasta que el navegador recibe el HTML generado.

En los ejemplos se utilizarán clases Java sencillas y colecciones en memoria. Esto permitirá trabajar con información realista sin introducir todavía persistencia, JPA ni bases de datos.

Una pregunta que debemos poder responder

Cuando termine la unidad, debería poder explicarse con claridad lo siguiente:

¿Quién recibe la petición, quién prepara los datos, quién genera el HTML y qué recibe finalmente el navegador?

6️⃣ Al finalizar la unidad​

Al terminar esta unidad se debería ser capaz de crear una pequeña aplicación Spring Boot formada por varias páginas dinámicas y entender el recorrido completo que sigue una petición.

Se podrá:

  • asociar rutas a métodos de un controlador;
  • devolver vistas Thymeleaf;
  • enviar información mediante Model;
  • mostrar valores y propiedades de objetos;
  • recorrer colecciones;
  • generar contenido condicional;
  • reutilizar fragmentos HTML;
  • incorporar recursos estáticos;
  • y reconocer las responsabilidades básicas de cada elemento dentro de MVC.

Todo lo aprendido servirá de base para el siguiente paso: recibir información introducida por el usuario y procesarla en el servidor.
