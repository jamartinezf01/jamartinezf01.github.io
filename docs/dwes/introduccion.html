Desarrollo Web en Entorno Servidor

1️⃣ ¿Qué aprenderemos?​

En este módulo aprenderemos a desarrollar aplicaciones web cuya lógica principal se ejecuta en el servidor. Partiremos del funcionamiento básico de una aplicación web y de la comunicación entre cliente y servidor para avanzar, de forma progresiva, hacia aplicaciones completas desarrolladas con Java y Spring Boot.

A lo largo del curso trabajaremos con peticiones HTTP, controladores, rutas, formularios, vistas dinámicas con Thymeleaf, acceso a bases de datos mediante Spring Data JPA, mantenimiento del estado mediante sesiones y cookies, autenticación y autorización y desarrollo de servicios web mediante APIs REST.

El objetivo no será únicamente aprender a utilizar Spring Boot, sino comprender qué ocurre detrás de una aplicación web, cómo se relacionan sus componentes y por qué se toman determinadas decisiones de diseño. Conceptos como la separación entre presentación y lógica de negocio, la organización por responsabilidades o el uso del patrón MVC se irán introduciendo de forma transversal, cuando resulten necesarios dentro de las distintas unidades.

En la última parte del módulo combinaremos tecnologías de servidor y cliente para construir aplicaciones más completas, consumir servicios desde JavaScript, actualizar información de forma dinámica y desarrollar un proyecto integrador.

Idea principal

Spring Boot será la tecnología principal del módulo, pero antes de utilizarlo necesitaremos comprender cómo funciona una aplicación web y cómo se comunican cliente y servidor.

Los conceptos aprendidos podrán trasladarse posteriormente a otros lenguajes, frameworks y plataformas.

2️⃣ Organización del módulo​

El módulo se organiza en siete unidades de trabajo. Cada una parte de los conceptos anteriores y añade nuevas capacidades, de forma que las aplicaciones desarrolladas serán progresivamente más completas.

🟩 UT1 – Arquitectura web y fundamentos​

Comenzaremos entendiendo cómo funciona una aplicación web antes de introducir un framework.

Trabajaremos:

  1. Arquitectura cliente-servidor.
  2. Diferencias entre ejecución en cliente y en servidor.
  3. Funcionamiento básico de HTTP.
  4. Peticiones y respuestas.
  5. Códigos de estado y cabeceras principales.
  6. Generación dinámica de contenido.
  7. Servidores web y servidores de aplicaciones.
  8. Tecnologías de desarrollo web en servidor.
  9. Simulación del funcionamiento de peticiones y respuestas HTTP mediante Java.
En esta unidad

Todavía no utilizaremos Spring Boot.

El objetivo será comprender primero el funcionamiento general de una aplicación web y los conceptos sobre los que trabajaremos posteriormente con el framework.

🟨 UT2 – Controladores, vistas y Thymeleaf​

Una vez comprendido el funcionamiento general de una aplicación web, comenzaremos a desarrollar aplicaciones con Spring Boot.

El recorrido de la unidad será progresivo:

  1. Creación de un proyecto con Spring Initializr.
  2. Estructura básica de un proyecto Spring Boot.
  3. Dependencias y funcionamiento básico de Maven.
  4. Controladores y rutas con Spring MVC.
  5. Organización de rutas mediante @RequestMapping y @GetMapping.
  6. Parámetros de petición con @RequestParam y @PathVariable.
  7. Devolución de vistas Thymeleaf.
  8. Uso de Model para enviar datos a una vista.
  9. Objetos Java como datos de la vista.
  10. Expresiones ${...} y @{...}.
  11. Construcción de enlaces y referencias a recursos.
  12. Recursos estáticos.
  13. Colecciones en las vistas.
  14. Bucles con th:each.
  15. Condicionales con th:if y th:unless.
  16. Integración progresiva de todos estos elementos en una misma aplicación.

A lo largo de la unidad desarrollaremos una aplicación que irá creciendo en varias fases, de modo que cada actividad reutilizará y ampliará el trabajo anterior.

🟧 UT3 – Formularios y validación​

En esta unidad aprenderemos a recibir y procesar información enviada por el usuario desde una página web.

Trabajaremos:

  1. Formularios HTML.
  2. Envío de datos mediante GET y POST.
  3. Diferencias entre ambos métodos en el contexto de formularios.
  4. Recepción de datos en controladores.
  5. Binding de formularios con objetos Java.
  6. Validación de datos.
  7. Mensajes de error.
  8. Conservación y presentación de errores en las vistas.
  9. Redirecciones.
  10. Datos temporales asociados a una redirección.
  11. Flujo completo entre formulario, controlador y vista.
  12. Separación de responsabilidades durante el procesamiento de formularios.

Los conceptos de rutas y parámetros ya introducidos en la UT2 se reutilizarán aquí dentro de un problema nuevo: el procesamiento de formularios.

🟥 UT4 – Persistencia con Spring Data JPA​

Hasta este momento los datos utilizados por nuestras aplicaciones serán temporales o estarán creados directamente desde Java. En esta unidad incorporaremos persistencia real mediante bases de datos.

Trabajaremos:

  1. Integración de una base de datos en Spring Boot.
  2. Introducción a JPA e Hibernate.
  3. Entidades.
  4. Identificadores y propiedades persistentes.
  5. Repositorios con Spring Data.
  6. Operaciones CRUD.
  7. Relaciones básicas entre entidades.
  8. Consultas.
  9. Introducción de una capa de servicio cuando la aplicación lo necesite.
  10. Organización Controller → Service → Repository.
  11. Integración de la persistencia con controladores y vistas.
  12. Prueba y documentación de aplicaciones con acceso a datos.

La organización por capas no se introducirá como una estructura artificial desde el principio. Aparecerá cuando el crecimiento de la aplicación haga necesario separar mejor sus responsabilidades.

🟪 UT5 – Sesiones, cookies y seguridad​

Una aplicación web recibe peticiones independientes, pero en muchas ocasiones necesita recordar información entre ellas e identificar al usuario que está utilizando el sistema.

Trabajaremos:

  1. Estado en aplicaciones web.
  2. Cookies.
  3. Sesiones HTTP.
  4. Mantenimiento de información entre peticiones.
  5. Autenticación.
  6. Introducción a Spring Security.
  7. Login y logout.
  8. Usuarios y roles.
  9. Rutas públicas y privadas.
  10. Autorización básica.
  11. Prueba y depuración de aplicaciones con estado y autenticación.

🟩 UT6 – APIs REST​

Además de generar páginas HTML, una aplicación servidor puede ofrecer datos y operaciones para que otras aplicaciones puedan utilizarlos.

Trabajaremos:

  1. Concepto de servicio web.
  2. Principios básicos de REST.
  3. Recursos y URL.
  4. HTTP aplicado a APIs.
  5. Controladores REST.
  6. @RestController.
  7. Representación de datos mediante JSON.
  8. Métodos HTTP en una API REST.
  9. Recepción de datos mediante @RequestBody.
  10. Uso de objetos específicos para intercambio de datos cuando resulte necesario.
  11. Operaciones CRUD mediante una API.
  12. Validación.
  13. Gestión de errores.
  14. Pruebas de servicios con Insomnia.
  15. Documentación básica de servicios.
Herramienta de referencia

Para probar las APIs REST utilizaremos Insomnia.

Postman puede emplearse como alternativa, pero no será la herramienta de referencia del módulo.

🟨 UT7 – Integración cliente-servidor y proyecto final​

En la última unidad integraremos los conocimientos adquiridos y veremos cómo una aplicación cliente puede comunicarse con los servicios desarrollados en el servidor.

Trabajaremos:

  1. Integración de las distintas partes de una aplicación.
  2. Combinación de vistas y APIs.
  3. Diferencias y complementariedad entre tecnologías cliente y servidor.
  4. Consumo de servicios desde JavaScript.
  5. Uso de fetch() para realizar peticiones HTTP.
  6. Peticiones asíncronas.
  7. Procesamiento de respuestas.
  8. Actualización dinámica del DOM.
  9. Gestión básica de errores en el cliente.
  10. Pruebas de la aplicación.
  11. Documentación.
  12. Preparación para el despliegue.
  13. Desarrollo de un proyecto final integrador.

5️⃣ Forma de trabajo​

El aprendizaje tendrá un enfoque principalmente práctico. Los conceptos se introducirán a medida que sean necesarios para resolver problemas concretos y se acompañarán de ejemplos guiados, ejercicios y aplicaciones progresivamente más completas.

En la UT1 comenzaremos sin Spring Boot para comprender cómo funciona una aplicación web, cómo se comunican cliente y servidor y qué papel desempeña HTTP.

A partir de la UT2 comenzaremos a utilizar Spring Boot. Primero trabajaremos con controladores, rutas y vistas sencillas y, progresivamente, incorporaremos datos dinámicos, formularios, persistencia, sesiones, seguridad y servicios web.

Algunas unidades utilizarán proyectos que evolucionarán durante varias actividades. De esta forma podremos comprobar cómo una misma aplicación crece cuando aparecen nuevas necesidades, en lugar de comenzar siempre desde cero.

La organización del código también evolucionará a medida que las aplicaciones crezcan. La separación entre controladores, servicios, repositorios y vistas no se estudiará como una estructura aislada, sino como una necesidad que aparecerá de forma natural al desarrollar proyectos más complejos.

No pretendemos memorizar anotaciones o fragmentos de código. El objetivo es comprender qué función cumple cada elemento dentro de una aplicación web, saber relacionarlo con los conceptos que hay detrás y ser capaces de aplicarlo en situaciones nuevas.

aviso

Spring Boot facilita gran parte de la configuración necesaria para desarrollar aplicaciones web, pero utilizar un framework sin comprender qué ocurre detrás suele provocar dificultades cuando aparecen errores.

Por este motivo, antes de automatizar un proceso intentaremos comprender qué problema está resolviendo.
