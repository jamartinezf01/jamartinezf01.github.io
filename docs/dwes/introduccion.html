🌐 Desarrollo Web en Entorno Servidor

1️⃣ ¿Qué aprenderemos?​

En este módulo aprenderemos a desarrollar aplicaciones web cuya lógica principal se ejecuta en el servidor. Partiremos del funcionamiento básico de una aplicación web y de la comunicación entre cliente y servidor para avanzar, de forma progresiva, hacia aplicaciones completas desarrolladas con Java y Spring Boot.

A lo largo del curso se trabajará con controladores, rutas, peticiones HTTP, formularios, vistas dinámicas con Thymeleaf, organización del código, acceso a bases de datos mediante Spring Data JPA, mantenimiento del estado mediante sesiones y cookies, autenticación y autorización y desarrollo de servicios web mediante APIs REST.

El objetivo no será únicamente aprender a utilizar Spring Boot, sino comprender qué ocurre detrás de una aplicación web, cómo se relacionan sus componentes y por qué se toman determinadas decisiones de diseño. Conceptos como la separación entre presentación y lógica de negocio, la organización por responsabilidades o el uso de patrones como MVC se irán introduciendo de forma transversal, cuando resulten necesarios dentro de las distintas unidades.

En la última parte del módulo se combinarán tecnologías de servidor y cliente para construir aplicaciones más completas, consumir servicios desde JavaScript, realizar pruebas y documentar el trabajo desarrollado.

Idea principal

Spring Boot será la tecnología principal del módulo, pero el objetivo será aprender conceptos de desarrollo web en entorno servidor que puedan trasladarse posteriormente a otros lenguajes, frameworks y plataformas.

2️⃣ Organización del módulo​

El módulo se organiza en siete unidades de trabajo. Cada una introduce nuevos conceptos sobre los anteriores, de manera que las aplicaciones desarrolladas serán progresivamente más completas.

UT1 – Arquitectura web y fundamentos​

Comenzaremos analizando cómo funciona una aplicación web y qué diferencias existen entre la ejecución de código en el cliente y en el servidor.

Se trabajarán conceptos como:

  1. Arquitectura cliente-servidor.
  2. Funcionamiento básico de HTTP.
  3. Peticiones y respuestas.
  4. Generación dinámica de contenido.
  5. Tecnologías de desarrollo web en servidor.
  6. Servidores web y servidores de aplicaciones.
  7. Introducción a Java y Spring Boot en aplicaciones web.
  8. Spring Initializr y creación de un proyecto.
  9. Estructura básica de una aplicación Spring Boot.
  10. Primeros controladores, rutas y parámetros.

UT2 – Controladores, vistas y Thymeleaf​

Una vez comprendido el funcionamiento general de una aplicación web, aprenderemos a generar contenido dinámico desde el servidor y a separar la lógica de la aplicación de su presentación.

Se trabajarán:

  1. Controladores y rutas.
  2. Devolución de vistas desde Spring Boot.
  3. Uso de Model.
  4. Plantillas Thymeleaf.
  5. Variables y expresiones.
  6. Operadores.
  7. Condicionales.
  8. Bucles y colecciones.
  9. Fragmentos y plantillas reutilizables.
  10. Recursos estáticos.
  11. Introducción al patrón MVC.

UT3 – Formularios y validación​

En esta unidad aprenderemos a recibir, procesar y validar la información que el usuario envía desde una página web.

Se trabajarán:

  1. Formularios HTML.
  2. Envío de datos mediante GET y POST.
  3. Parámetros de las peticiones.
  4. @RequestParam.
  5. @PathVariable.
  6. Binding de formularios con objetos Java.
  7. Validación de datos.
  8. Mensajes de error.
  9. Redirecciones.
  10. Flujo completo entre formulario, servidor y vista.
  11. Separación de responsabilidades en el procesamiento de formularios.

UT4 – Persistencia con Spring Data JPA​

Hasta este momento los datos utilizados por las aplicaciones serán temporales o simulados. En esta unidad incorporaremos persistencia real mediante bases de datos.

Se trabajarán:

  1. Integración de una base de datos en Spring Boot.
  2. Introducción a JPA e Hibernate.
  3. Entidades.
  4. Identificadores y propiedades persistentes.
  5. Repositorios con Spring Data.
  6. Operaciones CRUD.
  7. Relaciones básicas entre entidades.
  8. Consultas.
  9. Capa de servicio.
  10. Organización Controller → Service → Repository.
  11. Integración de la persistencia con controladores y vistas.
  12. Prueba y documentación de aplicaciones con acceso a datos.

UT5 – Sesiones, cookies y seguridad​

Las aplicaciones web necesitan mantener información entre diferentes peticiones e identificar a los usuarios que acceden a ellas.

Se trabajarán:

  1. Estado en aplicaciones web.
  2. Cookies.
  3. Sesiones HTTP.
  4. Mantenimiento de información entre peticiones.
  5. Autenticación.
  6. Introducción a Spring Security.
  7. Login y logout.
  8. Usuarios y roles.
  9. Rutas públicas y privadas.
  10. Prueba y depuración de aplicaciones con estado y autenticación.

UT6 – APIs REST​

Además de generar páginas HTML, una aplicación servidor puede ofrecer datos y funcionalidades para que otras aplicaciones puedan utilizarlos.

Se trabajarán:

  1. Concepto de servicio web.
  2. Características y ventajas de los servicios web.
  3. Principios básicos de REST.
  4. HTTP aplicado a APIs.
  5. Controladores REST.
  6. JSON.
  7. Métodos HTTP.
  8. @RestController.
  9. @RequestBody.
  10. Operaciones CRUD mediante una API.
  11. Validación y gestión de errores.
  12. Pruebas de servicios con Insomnia.
  13. Consumo de APIs.
  14. Documentación básica de servicios.

UT7 – Integración, pruebas y proyecto final​

En la última unidad integraremos los conocimientos adquiridos para desarrollar aplicaciones web más completas y combinar tecnologías de servidor y cliente.

Se trabajarán:

  1. Integración de las distintas capas de una aplicación.
  2. Combinación de vistas y APIs.
  3. Diferencias y complementariedad entre tecnologías cliente y servidor.
  4. Consumo de servicios desde JavaScript.
  5. Uso de fetch() para comunicarse con una API.
  6. Actualización dinámica del contenido de una página.
  7. Validación e interacción en el cliente.
  8. Pruebas básicas de la aplicación.
  9. Documentación.
  10. Preparación para el despliegue.
  11. Desarrollo de un proyecto final integrador.

5️⃣ Forma de trabajo​

El aprendizaje tendrá un enfoque principalmente práctico. Los conceptos se introducirán a medida que sean necesarios para resolver problemas concretos y se acompañarán de ejemplos guiados, ejercicios y pequeñas aplicaciones.

A lo largo del módulo iremos construyendo aplicaciones cada vez más completas. Al principio trabajaremos con ejemplos muy sencillos para comprender el funcionamiento de Spring Boot y, progresivamente, incorporaremos vistas, formularios, persistencia, seguridad y servicios web.

La organización del código también evolucionará a medida que las aplicaciones crezcan. La separación entre controladores, servicios, repositorios y vistas no se estudiará como un contenido aislado, sino como una necesidad que aparecerá de forma natural al desarrollar proyectos más complejos.

No se pretende memorizar anotaciones o fragmentos de código, sino comprender qué función cumple cada elemento dentro de una aplicación web y ser capaz de aplicarlo en situaciones nuevas.

aviso

Spring Boot facilita gran parte de la configuración necesaria para desarrollar aplicaciones web, pero utilizar un framework sin comprender qué ocurre detrás suele provocar dificultades cuando aparecen errores. Por este motivo, antes de automatizar un proceso intentaremos comprender qué problema está resolviendo.
