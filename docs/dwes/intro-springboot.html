UT2. Introducción a Spring y Spring Boot. Controladores, vistas y Thymeleaf

En la unidad anterior se estudió cómo funciona una aplicación web desde el punto de vista de la arquitectura cliente-servidor y del protocolo HTTP. Ya conocemos qué es una petición, qué información puede contener, cómo responde un servidor y qué significa generar contenido dinámicamente.

En esta unidad comenzaremos a utilizar Spring Boot para llevar esas ideas a una aplicación Java real.

El recorrido será progresivo. Primero crearemos y pondremos en marcha un proyecto sencillo. Después aprenderemos a asociar rutas con código Java, recibir datos desde las peticiones y, finalmente, generar páginas HTML dinámicas mediante Thymeleaf.

Idea principal

Durante la unidad construiremos el recorrido completo de una petición dentro de una aplicación Spring Boot:

petición HTTP → controlador → datos → vista Thymeleaf → HTML → respuesta HTTP

1️⃣ Qué vamos a aprender​

Al finalizar la unidad, el alumnado deberá ser capaz de:

  • crear y ejecutar un proyecto web básico con Spring Boot.
  • reconocer los elementos esenciales de su estructura.
  • comprender el papel de Maven y del archivo pom.xml a un nivel básico.
  • crear controladores con @Controller.
  • asociar rutas a métodos Java mediante @GetMapping.
  • distinguir entre devolver texto directamente y devolver una vista.
  • recibir información sencilla desde una petición mediante @RequestParam y @PathVariable.
  • utilizar Model para enviar datos desde el controlador hasta una plantilla.
  • comprender qué es Thymeleaf y dónde se procesa.
  • mostrar valores y propiedades de objetos mediante expresiones de Thymeleaf.
  • generar enlaces y utilizar atributos dinámicos.
  • construir contenido condicional.
  • recorrer colecciones para generar listados o tablas.
  • incorporar recursos estáticos como CSS e imágenes.
  • relacionar controlador, datos y vista dentro de una aplicación web sencilla.

No utilizaremos todavía una base de datos. Los datos de los ejemplos y actividades se crearán directamente desde Java mediante objetos y colecciones en memoria.

aviso

En esta unidad no profundizaremos todavía en formularios, @PostMapping, binding con objetos, validación, persistencia, JPA, seguridad ni arquitectura completa por capas.

Esos contenidos se introducirán cuando realmente sean necesarios en unidades posteriores.
