Tecnologías de desarrollo en servidor

Hasta ahora hemos visto que una aplicación web puede necesitar generar contenido dinámico en el servidor antes de enviarlo al navegador.

Para hacerlo existen diferentes lenguajes, frameworks y plataformas. Todos persiguen un objetivo parecido: recibir una petición HTTP, ejecutar la lógica necesaria y generar una respuesta.

1️⃣ Lenguajes y frameworks del lado servidor​

No todas las aplicaciones web de servidor se desarrollan con la misma tecnología. Algunas empresas trabajan con Java, otras con PHP, otras con Python y otras con JavaScript en el servidor. Cada ecosistema tiene sus herramientas, su forma de organizar los proyectos y sus convenciones.

Lo importante en esta unidad no es elegir “la mejor tecnología”, sino reconocer que todas resuelven problemas parecidos: recibir peticiones, ejecutar código en el servidor, preparar datos y devolver una respuesta al cliente.

Algunas de las más habituales son:

LenguajeTecnología habitual
JavaSpring Boot
PythonDjango
JavaScriptNode.js + Express
PHPLaravel
C#ASP.NET Core
RubyRuby on Rails

Aunque utilizan lenguajes y herramientas diferentes, todas permiten construir aplicaciones capaces de:

  • recibir peticiones HTTP.
  • procesar datos.
  • acceder a bases de datos.
  • aplicar lógica de negocio.
  • generar respuestas dinámicas.
  • desarrollar APIs para otras aplicaciones.
nota

No necesitamos aprender todas estas tecnologías.

En este módulo utilizaremos principalmente Java con Spring Boot, pero es importante conocer que existen otras alternativas muy utilizadas en el desarrollo web.

2️⃣ Algunos ejemplos​

🟩 Spring Boot​

Spring Boot es un framework basado en Java que facilita la creación de aplicaciones web y APIs.

Permite crear aplicaciones que incluyen su propio servidor web embebido, por lo que pueden ejecutarse directamente sin necesidad de instalar un servidor de aplicaciones externo.

En este módulo será nuestra tecnología principal.

🟨 Django​

Django es un framework de desarrollo web escrito en Python.

Proporciona numerosas funcionalidades ya preparadas, como:

  • gestión de rutas.
  • acceso a bases de datos.
  • autenticación de usuarios.
  • generación de páginas dinámicas.

Es especialmente habitual en aplicaciones desarrolladas con Python.

🟧 Node.js y Express​

Node.js permite ejecutar JavaScript fuera del navegador y utilizarlo también en el servidor.

Sobre Node.js pueden utilizarse diferentes frameworks. Uno de los más conocidos es Express.

De esta forma es posible desarrollar tanto el cliente como el servidor utilizando JavaScript.

🟥 Laravel​

Laravel es un framework para el lenguaje PHP.

PHP lleva muchos años utilizándose en el desarrollo web y continúa siendo una tecnología muy extendida.

Laravel proporciona una estructura moderna para desarrollar aplicaciones web y facilita tareas como el acceso a bases de datos, las rutas o la autenticación.

🟪 ASP.NET Core​

ASP.NET Core es la plataforma de Microsoft para desarrollar aplicaciones web utilizando principalmente C#.

Permite crear aplicaciones web, servicios y APIs y puede ejecutarse en distintos sistemas operativos.

🟦 Ruby on Rails​

Ruby on Rails es un framework de desarrollo web basado en Ruby. Es conocido por su enfoque basado en convenciones y por facilitar la creación rápida de aplicaciones web.

No lo utilizaremos en el módulo, pero es otro ejemplo de tecnología de servidor que sigue la misma lógica general: recibir peticiones, ejecutar código y generar respuestas.

aviso

En esta unidad no vamos a aprender Django, Laravel, Express ni ASP.NET Core. Los mencionamos para situar Spring Boot dentro de un ecosistema más amplio de tecnologías de servidor.

3️⃣ Todas siguen una idea similar​

Aunque cada tecnología utiliza una sintaxis y unas herramientas diferentes, el funcionamiento general de una aplicación web es muy parecido:

Por ejemplo, una petición podría ser:

GET /productos

La aplicación recibe esa petición, ejecuta la lógica correspondiente y genera una respuesta.

La forma concreta de programarlo cambiará dependiendo de si utilizamos Spring Boot, Django, Express, Laravel u otra tecnología.

4️⃣ ¿Por qué utilizaremos Spring Boot?​

En este módulo trabajaremos principalmente con Spring Boot porque permite desarrollar aplicaciones web modernas utilizando Java.

A lo largo del módulo, Spring Boot nos permitirá trabajar con:

  • creación de aplicaciones web.
  • controladores y rutas.
  • vistas HTML generadas desde el servidor.
  • validación de datos.
  • acceso a bases de datos.
  • APIs REST.
  • seguridad.
  • gestión de dependencias con Maven.
  • servidor embebido durante el desarrollo.

En esta unidad solo haremos una primera aproximación. Muchos de esos elementos se estudiarán más adelante, cuando ya tengamos una base suficiente.

A partir de este punto comenzaremos a trabajar con Spring Boot y veremos cómo crear nuestra primera aplicación web en entorno servidor.

tip

Lo importante no es memorizar todos los frameworks existentes.

Debemos comprender que una aplicación web de servidor puede construirse con distintas tecnologías y que Spring Boot es una de ellas.
