Estructura de un proyecto Spring Boot

Una vez entendido qué es Spring Boot, el siguiente paso es conocer cómo se organiza un proyecto.

Cuando creamos una aplicación Spring Boot aparecen varias carpetas y archivos. Al principio pueden parecer muchos, pero no todos tienen la misma importancia.

En esta unidad nos centraremos únicamente en los elementos que necesitaremos para empezar a desarrollar.

1️⃣ Estructura general del proyecto​

Un proyecto Spring Boot suele tener una estructura parecida a esta:

en este ejemplo
  • src/main/java contiene el código Java de nuestra aplicación.
  • src/main/resources contiene archivos de configuración y otros recursos.
  • src/test se utiliza para las pruebas.
  • pom.xml contiene la configuración de Maven y las dependencias del proyecto.

No necesitamos memorizar toda la estructura desde el primer momento.

La idea principal es distinguir claramente dónde va el código Java y dónde van los recursos y la configuración.

2️⃣ La carpeta src/main/java​

La carpeta:

src/main/java

contiene el código Java de la aplicación.

Dentro encontraremos los paquetes y las clases que iremos creando durante el curso.

Por ejemplo:

src/main/java/
└── com/
    └── ejemplo/
        └── tienda/
            └── TiendaApplication.java
en este ejemplo

La ruta de carpetas representa el paquete Java.

En este ejemplo, la clase TiendaApplication estaría dentro del paquete:

com.ejemplo.tienda

Más adelante iremos añadiendo nuevas clases dentro de este espacio.

3️⃣ La carpeta src/main/resources​

La carpeta:

src/main/resources

contiene archivos que utiliza la aplicación pero que no son clases Java.

Entre ellos encontraremos especialmente:

application.properties

También podremos guardar aquí:

  • archivos de configuración;
  • plantillas;
  • recursos estáticos;
  • otros archivos que necesite la aplicación.

En esta primera unidad nos interesa principalmente el archivo application.properties.

4️⃣ La clase principal​

Todo proyecto Spring Boot tiene una clase principal que sirve para arrancar la aplicación.

Su estructura será parecida a esta:

@SpringBootApplication
public class TiendaApplication {

    public static void main(String[] args) {
        SpringApplication.run(TiendaApplication.class, args);
    }
}
en este ejemplo
  • @SpringBootApplication identifica la clase principal de Spring Boot.
  • main() es el punto de entrada de la aplicación Java.
  • SpringApplication.run(...) inicia Spring Boot.
  • Durante ese arranque también se pone en marcha el servidor web embebido.

Esta clase suele encontrarse en el paquete principal del proyecto.

tip

Durante las primeras prácticas apenas tendremos que modificar esta clase.

Su función principal será arrancar la aplicación.

5️⃣ El archivo application.properties​

Dentro de:

src/main/resources

encontraremos normalmente:

application.properties

Este archivo se utiliza para configurar determinados aspectos de la aplicación.

Por ejemplo, podemos cambiar el puerto donde escucha el servidor:

server.port=8081
en este ejemplo

Por defecto, una aplicación web Spring Boot suele utilizar el puerto 8080.

Con esta propiedad indicamos que queremos utilizar el puerto 8081.

En ese caso accederíamos a la aplicación mediante:

http://localhost:8081

Durante el curso iremos utilizando este archivo para configurar distintos elementos cuando sea necesario.

6️⃣ El archivo pom.xml​

En la raíz del proyecto encontraremos:

pom.xml

Este archivo pertenece a Maven.

Como vimos anteriormente, Maven se encarga de gestionar las dependencias del proyecto.

Dentro del pom.xml aparecen, entre otras cosas:

  • información del proyecto;
  • versión de Java;
  • dependencias;
  • plugins utilizados durante la construcción.

Un fragmento de dependencias puede tener un aspecto parecido a este:

<dependencies>

    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>

</dependencies>
en este ejemplo

Esta dependencia añade el starter Spring Web.

Gracias a ella nuestro proyecto incorpora las herramientas necesarias para desarrollar una aplicación web con Spring Boot.

nota

No necesitamos aprender de memoria la sintaxis de Maven.

Lo importante es saber localizar el pom.xml y entender que en él declaramos las dependencias que necesita nuestro proyecto.

7️⃣ Organización mediante paquetes​

A medida que una aplicación crece, no conviene guardar todas las clases en el mismo lugar.

Utilizaremos paquetes para organizar el código según su función.

Una organización habitual puede ser:

com.ejemplo.tienda
│
├── controller
├── service
├── repository
└── model

Cada paquete tendrá una responsabilidad diferente.

PaqueteFunción general
controllerRecibir peticiones y devolver respuestas
serviceContener la lógica de la aplicación
repositoryAcceder a los datos
modelRepresentar los datos de la aplicación
nota

No utilizaremos todos estos paquetes desde el primer ejercicio.

Los iremos incorporando progresivamente cuando realmente los necesitemos.

8️⃣ ¿Dónde irá cada cosa?​

Podemos visualizar la organización de una aplicación de esta forma:

Cliente
   ↓
controller
   ↓
service
   ↓
repository
   ↓
Base de datos

Cada parte tiene una responsabilidad concreta.

Por ahora nos centraremos principalmente en los controladores, porque serán los encargados de recibir nuestras primeras peticiones HTTP.

Más adelante iremos incorporando las demás capas.

9️⃣ Elementos que no necesitamos tocar al principio​

Los entornos de desarrollo y Spring Boot pueden generar otros archivos y carpetas.

Por ejemplo:

.mvn/
mvnw
mvnw.cmd
target/
.gitignore

No necesitamos trabajar directamente con todos ellos en nuestras primeras aplicaciones.

De momento podemos pensar en el proyecto de forma simplificada:

Proyecto Spring Boot
│
├── src/main/java
│      └── Código Java
│
├── src/main/resources
│      └── Configuración
│
└── pom.xml
       └── Dependencias
tip

Si al principio dudas sobre dónde buscar algo, piensa en estas tres preguntas:

  • ¿Es código Java? → src/main/java
  • ¿Es configuración o un recurso? → src/main/resources
  • ¿Es una dependencia? → pom.xml

🔟 Resumen​

Ya conocemos las piezas principales de un proyecto Spring Boot:

ElementoFunción
src/main/javaCódigo Java
src/main/resourcesRecursos y configuración
Clase principalArranca Spring Boot
application.propertiesConfigura la aplicación
pom.xmlGestiona dependencias con Maven
PaquetesOrganizan las clases según su responsabilidad
