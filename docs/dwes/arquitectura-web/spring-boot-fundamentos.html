Fundamentos de Spring Boot

En los apartados anteriores hemos visto que existen distintas tecnologías para desarrollar aplicaciones web en el lado servidor.

En este módulo utilizaremos principalmente Java con Spring Boot.

Spring Boot nos permitirá crear aplicaciones capaces de:

  • recibir peticiones HTTP.
  • ejecutar lógica en el servidor.
  • acceder a bases de datos.
  • generar respuestas dinámicas.
  • desarrollar APIs REST.

Antes de empezar a programar, necesitamos entender qué es Spring Boot y qué ocurre cuando ejecutamos una aplicación.

1️⃣ ¿Qué es Spring?​

Spring es un ecosistema de herramientas para desarrollar aplicaciones con Java.

Proporciona soluciones para muchos problemas habituales del desarrollo de aplicaciones:

  • aplicaciones web.
  • acceso a bases de datos.
  • seguridad.
  • validación.
  • gestión de objetos.
  • creación de APIs.
  • pruebas.

El problema es que una aplicación Spring tradicional puede necesitar bastante configuración.

Ahí aparece Spring Boot.

2️⃣ ¿Qué es Spring Boot?​

Spring Boot es una herramienta basada en Spring que simplifica la creación y configuración de aplicaciones Java.

Su objetivo principal es permitir que podamos comenzar a desarrollar una aplicación rápidamente, evitando gran parte de la configuración manual.

Podemos pensar en Spring Boot como una capa que nos proporciona muchas decisiones y configuraciones ya preparadas.

nota

Spring Boot no sustituye a Spring.

Spring Boot utiliza Spring y facilita su configuración y puesta en marcha.

3️⃣ Una aplicación lista para ejecutarse​

Una de las características más importantes de Spring Boot es que permite crear aplicaciones que pueden ejecutarse directamente.

En muchos casos basta con iniciar la aplicación Java:

Aplicación Spring Boot
        ↓
Se inicia
        ↓
Arranca el servidor web
        ↓
La aplicación queda esperando peticiones HTTP

No necesitamos instalar y configurar manualmente un servidor de aplicaciones para empezar a trabajar.

4️⃣ El servidor web embebido​

Una aplicación web necesita un servidor que escuche las peticiones HTTP.

Spring Boot puede incluir ese servidor dentro de la propia aplicación.

A esto lo llamamos servidor embebido.

Por defecto, muchas aplicaciones Spring Boot utilizan Tomcat.

Cuando ejecutamos la aplicación:

  1. se inicia Java.
  2. se inicia Spring Boot.
  3. arranca el servidor web embebido.
  4. el servidor comienza a escuchar peticiones.
  5. nuestra aplicación puede responder a ellas.
tip

La idea importante es sencilla:

no tenemos que instalar Tomcat por separado para empezar a desarrollar.

Spring Boot puede incluirlo y arrancarlo automáticamente junto con nuestra aplicación.

6️⃣ Spring Boot utiliza dependencias​

Una aplicación real necesita muchas bibliotecas.

Por ejemplo, para crear una aplicación web necesitaremos componentes capaces de:

  • recibir peticiones HTTP.
  • trabajar con JSON.
  • arrancar un servidor.
  • gestionar rutas.
  • validar datos.

No descargaremos cada biblioteca manualmente.

Spring Boot permite declarar las funcionalidades que necesitamos mediante dependencias.

Por ejemplo, si queremos crear una aplicación web podemos añadir una dependencia preparada para desarrollo web.

Spring Boot se encargará de incorporar muchas de las bibliotecas necesarias.

8️⃣ Maven y el archivo pom.xml​

En nuestros proyectos utilizaremos normalmente Maven.

Maven es una herramienta que nos ayuda a gestionar:

  • las dependencias del proyecto.
  • la compilación.
  • la construcción de la aplicación.

Las dependencias se indican en un archivo llamado:

pom.xml

De momento no necesitamos conocer su sintaxis en profundidad.

Solo debemos quedarnos con esta idea:

pom.xml
   ↓
Indica qué necesita el proyecto
   ↓
Maven descarga las dependencias
   ↓
Spring Boot puede utilizarlas

Más adelante iremos modificando este archivo cuando necesitemos añadir nuevas funcionalidades.

🔟 La clase principal​

Todo proyecto Spring Boot tiene una clase que actúa como punto de entrada de la aplicación.

Su estructura será parecida a esta:

@SpringBootApplication
public class MiAplicacion {

    public static void main(String[] args) {
        SpringApplication.run(MiAplicacion.class, args);
    }
}
en este ejemplo
  • @SpringBootApplication indica que esta clase inicia y configura la aplicación Spring Boot.
  • El método main() es el punto de entrada habitual de una aplicación Java.
  • SpringApplication.run(...) pone en marcha Spring Boot.
  • Durante el arranque también se inicia el servidor web embebido.

No necesitamos comprender todavía todo lo que hace @SpringBootApplication.

Por ahora basta con entender que esta clase es la que utilizaremos para arrancar la aplicación.
