Tecnologías de desarrollo en servidor

Hasta ahora hemos visto que una aplicación web puede recibir peticiones, ejecutar código en el servidor y generar respuestas de forma dinámica.

Para desarrollar esa parte de la aplicación existen diferentes lenguajes, frameworks y plataformas. No todas las aplicaciones utilizan las mismas herramientas, pero muchas resuelven problemas muy parecidos.

Idea principal

La tecnología elegida puede cambiar, pero el funcionamiento general se mantiene: recibir una petición, ejecutar lógica en el servidor y devolver una respuesta al cliente.

1️⃣ No existe una única tecnología de servidor​

Una aplicación web de servidor puede desarrollarse con lenguajes y herramientas muy diferentes.

Algunas organizaciones trabajan principalmente con Java, otras con PHP, Python, JavaScript, C# o Ruby. Cada ecosistema dispone de herramientas que facilitan tareas habituales como recibir peticiones, organizar rutas, acceder a datos o generar respuestas.

Por ejemplo:

LenguajeTecnologíaTipo
JavaSpring BootFramework basado en Spring.
PythonDjangoFramework web.
JavaScriptNode.js + ExpressEntorno de ejecución + framework.
PHPLaravelFramework web.
C#ASP.NET CorePlataforma y framework web.
RubyRuby on RailsFramework web.

Esta tabla no pretende recoger todas las posibilidades. Existen muchas otras tecnologías y, además, un mismo lenguaje puede utilizarse con distintos frameworks.

🟩 Lenguaje, framework y plataforma no son lo mismo​

Conviene diferenciar estos conceptos.

Un lenguaje de programación es la herramienta con la que escribimos el código. Java, Python, JavaScript, PHP, C# y Ruby son ejemplos.

Un framework proporciona una estructura y un conjunto de herramientas para desarrollar aplicaciones siguiendo una forma de trabajo determinada. Spring Boot, Django o Laravel son ejemplos de tecnologías que facilitan la creación de aplicaciones web.

También podemos encontrarnos con entornos o plataformas de ejecución. Por ejemplo, Node.js permite ejecutar JavaScript fuera del navegador y utilizarlo en el servidor.

nota

No necesitamos memorizar ahora una clasificación exacta de todas las tecnologías. Lo importante es entender que una aplicación de servidor suele apoyarse en varias piezas que trabajan juntas.

2️⃣ Problemas parecidos, herramientas diferentes​

Aunque la sintaxis y la forma de organizar un proyecto cambien, las tecnologías de servidor suelen resolver necesidades muy similares.

Una aplicación puede necesitar:

  • recibir peticiones HTTP.
  • interpretar rutas y parámetros.
  • ejecutar lógica de la aplicación.
  • procesar la información recibida.
  • consultar o modificar datos.
  • generar HTML u otros tipos de respuesta.
  • devolver códigos de estado adecuados.
  • comunicarse con otras aplicaciones.

Por ejemplo, imaginemos esta petición:

GET /productos/3

Una aplicación podría estar desarrollada con Java y Spring Boot, con Python y Django o con JavaScript y Express.

En todos los casos, la idea general sería similar: la aplicación recibe una petición, ejecuta el procesamiento necesario y devuelve una respuesta.

La diferencia estaría en cómo se programa y organiza internamente la aplicación.

3️⃣ Algunos ecosistemas habituales​

No vamos a estudiar estas tecnologías en profundidad, pero conviene conocer algunas de las más utilizadas para situar la tecnología que emplearemos en el módulo.

🟩 Java y Spring Boot​

Java es un lenguaje muy utilizado en aplicaciones empresariales y en sistemas de servidor.

Dentro de su ecosistema existen distintas herramientas para el desarrollo web. En este módulo utilizaremos Spring Boot, que facilita la creación de aplicaciones web basadas en Java.

No entraremos todavía en su funcionamiento. Lo estudiaremos a partir de la siguiente unidad.

🟨 Python y Django​

Python también se utiliza para desarrollar aplicaciones web.

Uno de sus frameworks más conocidos es Django, que proporciona herramientas para organizar rutas, trabajar con datos, gestionar usuarios y generar contenido dinámico.

🟧 JavaScript, Node.js y Express​

JavaScript nació principalmente como lenguaje ejecutado en el navegador, pero también puede utilizarse en el servidor.

Node.js permite ejecutar JavaScript fuera del navegador y Express es uno de los frameworks que pueden utilizarse para crear aplicaciones web sobre ese entorno.

Esto permite utilizar JavaScript tanto en el cliente como en el servidor, aunque el código de ambas partes siga ejecutándose en lugares diferentes.

🟥 PHP y Laravel​

PHP es un lenguaje estrechamente relacionado con el desarrollo web en servidor.

Laravel es uno de sus frameworks actuales más conocidos y facilita tareas habituales como organizar rutas, trabajar con datos o construir aplicaciones web completas.

🟪 C# y ASP.NET Core​

ASP.NET Core es una plataforma utilizada para desarrollar aplicaciones web principalmente con C#.

Permite crear aplicaciones web, servicios y APIs que pueden ejecutarse en distintos sistemas operativos.

🟦 Ruby y Ruby on Rails​

Ruby on Rails es un framework basado en Ruby.

Es otro ejemplo de tecnología que proporciona una estructura ya preparada para desarrollar aplicaciones web sin tener que construir desde cero todas las piezas habituales.

aviso

El objetivo de este apartado no es aprender a programar con todas estas tecnologías ni decidir cuál es mejor. Solo necesitamos reconocer que existen diferentes alternativas para desarrollar la parte de servidor de una aplicación web.

4️⃣ Cómo encajan con lo que ya conocemos​

Independientemente de la tecnología elegida, todas estas aplicaciones siguen trabajando sobre conceptos que ya hemos estudiado.

Por ejemplo:

Cliente
   ↓
Petición HTTP
   ↓
Servidor web / aplicación de servidor
   ↓
Código de la aplicación
   ↓
Respuesta HTTP
   ↓
Cliente

La tecnología de desarrollo se sitúa principalmente en la parte donde se ejecuta el código de la aplicación en el servidor.

Esto significa que conceptos como cliente, servidor, rutas, métodos HTTP, cabeceras, códigos de estado o generación dinámica no pertenecen exclusivamente a Spring Boot, Django o cualquier otro framework.

Son conceptos generales del desarrollo web.

tip

Comprender primero estos conceptos permite cambiar de tecnología con más facilidad. La sintaxis puede ser diferente, pero el modelo de comunicación sigue siendo muy parecido.

5️⃣ La tecnología que utilizaremos en el módulo​

En DWES trabajaremos principalmente con Java y Spring Boot.

Con Spring Boot aplicaremos progresivamente estos conceptos generales a aplicaciones desarrolladas con Java.

Pero en esta unidad no necesitamos todavía conocer sus anotaciones, estructura de proyecto ni configuración.

Ese será el siguiente paso.

Por ahora debemos quedarnos con dos ideas:

  • Spring Boot es una de las tecnologías disponibles para desarrollar aplicaciones web en el servidor.
  • Los conceptos de arquitectura web y HTTP que estamos estudiando son independientes de la tecnología concreta que se utilice.
