UT1. Arquitectura web

En esta primera unidad vamos a sentar las bases necesarias para entender cómo funciona una aplicación web en entorno servidor.

Antes de comenzar a desarrollar aplicaciones web, es importante comprender qué ocurre desde que una persona solicita un recurso en el navegador hasta que el servidor procesa esa petición y devuelve una respuesta.

A lo largo de la unidad estudiaremos el modelo cliente-servidor, la comunicación mediante HTTP, la diferencia entre páginas estáticas y dinámicas y las principales tecnologías utilizadas para ejecutar código en el servidor.

Idea principal

Una aplicación web se basa en la comunicación entre un cliente y un servidor. El cliente realiza una petición, el servidor la procesa y devuelve una respuesta.

Comprender este proceso será la base para todo lo que desarrollaremos posteriormente.

1️⃣ Qué vamos a aprender en esta unidad​

Esta unidad tiene como objetivo comprender cómo se organiza y cómo se comunica una aplicación web.

A lo largo de los distintos apartados aprenderemos a:

  • diferenciar el papel del cliente y del servidor.
  • comprender cómo se produce la comunicación mediante HTTP.
  • interpretar la estructura básica de una petición HTTP.
  • interpretar la estructura básica de una respuesta HTTP.
  • reconocer métodos HTTP, rutas, cabeceras, cuerpos y códigos de estado.
  • diferenciar entre páginas estáticas y páginas dinámicas.
  • distinguir entre la ejecución de código en el cliente y en el servidor.
  • comprender el papel de los servidores web y los servidores de aplicaciones.
  • identificar las principales tecnologías utilizadas en la programación web en entorno servidor.

La finalidad no será memorizar el funcionamiento interno completo de HTTP, sino comprender los elementos que necesitaremos posteriormente al desarrollar aplicaciones web.

2️⃣ Resultado de aprendizaje trabajado​

En esta unidad se trabajará principalmente el RA1.

RA principal

RA1. Selecciona las arquitecturas y tecnologías de programación web en entorno servidor, analizando sus capacidades y características propias.

A través de los distintos contenidos se trabajarán los criterios de evaluación relacionados con:

  • la ejecución de código en cliente y servidor.
  • la generación dinámica de páginas web.
  • los mecanismos de ejecución de código en servidores web.
  • los servidores web y servidores de aplicaciones.
  • los principales lenguajes y tecnologías de programación en servidor.
  • la integración entre lenguajes de marcas y programación.
  • las herramientas y frameworks utilizados en desarrollo web en entorno servidor.

3️⃣ Contenidos de la unidad​

La unidad se organiza de forma progresiva, comenzando por el funcionamiento general de una aplicación web y profundizando después en la comunicación entre cliente y servidor.

🟩 1. Cómo funciona una aplicación web​

Identificaremos los principales elementos que intervienen cuando utilizamos una aplicación web y seguiremos el recorrido que realiza una solicitud desde el navegador hasta el servidor y de vuelta al cliente.

🟨 2. El modelo cliente-servidor​

Analizaremos qué responsabilidades corresponden al cliente y cuáles al servidor, y veremos por qué una aplicación web distribuye su funcionamiento entre ambos.

🟧 3. HTTP: comunicación entre cliente y servidor​

Estudiaremos el protocolo HTTP y el modelo de comunicación basado en peticiones y respuestas.

Veremos también cómo las URL permiten identificar los recursos a los que queremos acceder.

🟥 4. Peticiones HTTP​

Analizaremos los principales elementos que puede contener una petición:

  • método HTTP.
  • ruta o recurso solicitado.
  • versión del protocolo.
  • cabeceras.
  • cuerpo de la petición.

Trabajaremos especialmente con métodos como GET, POST y DELETE.

🟪 5. Respuestas HTTP​

Estudiaremos cómo responde un servidor después de procesar una petición.

Veremos:

  • códigos de estado.
  • mensajes asociados.
  • cabeceras.
  • cuerpo de la respuesta.

Trabajaremos con códigos habituales como 200, 201, 204, 400, 404 o 500.

🟦 6. Páginas estáticas y páginas dinámicas​

Compararemos ambos tipos de páginas para comprender por qué las aplicaciones web necesitan ejecutar código en el servidor y generar respuestas diferentes según la información disponible.

🟫 7. Ejecución de código en cliente y servidor​

Analizaremos dónde se ejecutan las distintas partes de una aplicación web y qué diferencias existen entre la programación en entorno cliente y la programación en entorno servidor.

⬛ 8. Servidores web y servidores de aplicaciones​

Estudiaremos qué funciones desempeñan estos servidores y cómo intervienen en el procesamiento y entrega de los recursos de una aplicación web.

⬜ 9. Tecnologías de programación en entorno servidor​

Finalmente, conoceremos diferentes lenguajes, herramientas y frameworks utilizados para desarrollar aplicaciones web en servidor y situaremos las tecnologías que utilizaremos posteriormente durante el módulo.

4️⃣ Aplicamos lo aprendido​

A lo largo de la unidad combinaremos el análisis de ejemplos con la observación de comunicaciones HTTP reales.

Utilizaremos las herramientas de desarrollo del navegador para identificar peticiones, respuestas, métodos, cabeceras y códigos de estado.

Como actividad de aplicación, desarrollaremos en Java un pequeño simulador de peticiones y respuestas HTTP.

El objetivo no será implementar un servidor web real, sino utilizar los conocimientos de Java trabajados previamente para representar el funcionamiento que hemos estudiado:

5️⃣ Antes de empezar​

Antes de avanzar, intenta responder brevemente:

  1. ¿Qué diferencia existe entre un cliente y un servidor?
  2. ¿Qué papel desempeña el navegador en una aplicación web?
  3. ¿Qué información crees que envía un navegador cuando solicita un recurso?
  4. ¿Cómo puede indicar un servidor si una petición se ha procesado correctamente o si se ha producido un error?
  5. ¿Qué diferencia crees que existe entre una página estática y una página dinámica?

No es necesario conocer todavía todas las respuestas.

A lo largo de la unidad iremos construyéndolas paso a paso.
